# Historias de usuario de Nivora

Las historias de usuario describen las necesidades de las personas
que consultan un suministro y del administrador de la plataforma.

Formato: Como [actor], quiero [acción], para [beneficio].

## Historias de usuario

| ID | Historia de usuario |
|----|---------------------|
| HU01 | Como usuario de consulta, quiero acceder ingresando un código de suministro existente y mi DNI válido, para consultar la información del hogar. |
| HU02 | Como usuario de consulta, quiero cerrar mi sesión, para finalizar el acceso al suministro desde el dispositivo utilizado. |
| HU03 | Como usuario de consulta, quiero conocer el consumo acumulado en litros y metros cúbicos, junto con la fecha de la última lectura y su estado de actualización, para saber cuánta agua se ha consumido y qué tan reciente es la información. |
| HU04 | Como usuario de consulta, quiero conocer el costo acumulado estimado y las tarifas utilizadas, para comprender cómo se calcula mi gasto durante el mes. |
| HU05 | Como usuario de consulta, quiero visualizar una proyección del consumo y costo al finalizar el mes si mantengo el ritmo actual, para anticipar mi gasto. |
| HU06 | Como usuario de consulta, quiero revisar el consumo y los costos estimados de meses anteriores, para conocer su evolución. |
| HU07 | Como usuario de consulta, quiero comparar periodos mediante gráficos y estadísticas, para identificar aumentos o disminuciones del consumo. |
| HU08 | Como usuario de consulta, quiero recibir una alerta cuando el consumo acumulado del mes actual supere el consumo total del mes anterior, para reconocer ese aumento y revisar mis hábitos de consumo. |
| HU09 | Como usuario de consulta, quiero habilitar o deshabilitar las notificaciones del suministro en mi dispositivo, para controlar la recepción de avisos. |
| HU10 | Como usuario de consulta, quiero recibir notificaciones en mi dispositivo aunque Nivora esté cerrada, para enterarme de las alertas de consumo y de la disponibilidad de recibos. |
| HU11 | Como usuario de consulta, quiero revisar las notificaciones dentro de Nivora y marcarlas como leídas, para distinguir los avisos pendientes de los que ya revisé. |
| HU12 | Como usuario de consulta, quiero consultar el recibo mensual y los recibos anteriores disponibles, para conocer sus importes definitivos y fechas límite de pago. |
| HU13 | Como usuario de consulta, quiero recibir un aviso cuando el recibo del mes esté disponible, indicando la fecha límite del plazo de una semana, para organizar su pago. |
| HU14 | Como administrador, quiero acceder mediante un mecanismo administrativo diferenciado, para utilizar las funciones de gestión según mis permisos. |
| HU15 | Como administrador, quiero consultar los suministros disponibles y los registros de acceso, para supervisar las consultas realizadas en la plataforma. |
| HU16 | Como administrador, quiero configurar los periodos mensuales de consumo, para organizar correctamente los cálculos, las comparaciones y los recibos. |
| HU17 | Como administrador, quiero gestionar las tarifas y sus fechas de vigencia, para que las estimaciones utilicen los valores correspondientes a cada periodo. |
| HU18 | Como administrador, quiero activar o desactivar la evaluación de alertas de consumo, para gestionar su funcionamiento en la plataforma. |
| HU19 | Como administrador, quiero consultar el estado de la integración y la última actualización de lecturas y recibos por suministro, para identificar interrupciones o información pendiente. |
| HU20 | Como administrador, quiero revisar las incidencias y solicitar nuevos intentos de actualización o procesamiento, para recuperar la información pendiente después de un fallo. |
| HU21 | Como administrador, quiero disponer de un entorno con datos simulados y distintos escenarios, para comprobar el funcionamiento de Nivora durante la demostración académica. |
